Fase 1 · Portão da Probabilidade

🎲 O que é o Log-Odds Ratio?

"O guardião da câmara pergunta: você sabe o que é uma razão de chances?"

O LOR compara a probabilidade de uma feature aparecer em uma classe versus fora dela. Qual é a interpretação correta?

Fase 2 · Pergaminho da Razão

📜 A fórmula do LOR

"Um pergaminho se desenrola revelando a fórmula. Complete-a para desbloquear o poder."
LOR(t, c) = log [ P(t|c) / (1 − P(t|c)) ]
              ÷
           [ P(t|¬c) / (1 − P(t|¬c)) ]

O que o numerador representa?

O numerador é a chance da feature estar presente dentro da classe. O denominador é a chance dela estar presente fora da classe. A razão entre os dois indica quanto a feature "favorece" a classe.
Fase 3 · Espelho da Interpretação

🪞 Como ler o LOR?

O LOR varia de −∞ a +∞. Observe a escala:

← −∞     0     +∞ →
assoc. negativa  |  neutro  |  assoc. positiva

Se um termo tem LOR = 0, o que isso significa?

LOR > 0: feature puxa para a classe (associação positiva).
LOR = 0: feature neutra (odds iguais dentro e fora).
LOR < 0: feature "empurra" para fora da classe (associação negativa).
Fase 4 · Abismo dos Eventos Raros

⚠️ O problema do infinito

"Um abismo se abre. Se uma feature nunca aparece fora da classe, o LOR explode para o infinito. Como atravessar?"

Se P(t|¬c) = 0, o denominador da fração se torna zero e o LOR vai para +∞. Qual é a solução padrão?

A suavização mais comum é o prior de Laplace (adicionar 1 a cada contagem) ou ELE (Expected Likelihood Estimate, adicionar 0.5). Isso evita divisão por zero e mantém o LOR finito e interpretável.

Fase 6 · Chefe Final

👹 O Filtro do Ruído

"Um demônio de mil palavras inúteis bloqueia a saída. Ele sussurra: 'Nem toda feature merece atenção. Prove que sabe selecionar as melhores!'"

Pergunta decisiva:

Você tem um vocabulário de 50.000 termos e precisa reduzir para 500 features para um classificador Naive Bayes. Como o LOR ajuda?

O LOR é uma métrica unilateral: identifica features positivamente correlacionadas com uma classe específica. É uma das técnicas mais eficazes de seleção de features em PLN, superando a simples frequência.
