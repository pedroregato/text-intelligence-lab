⚡ Top‑K: Geração vs Retrieval ⚡

Dois lugares, um mesmo nome, significados diferentes. Ajuste o K em cada lado e descubra por que tanta gente confunde os dois.

🧭 Antes de mexer: o que é "top‑k"?

Imagine que você pediu para alguém escolher as K melhores opções de uma lista gigante. Esse "K" é só um número: top‑3 significa "as 3 melhores", top‑50 significa "as 50 melhores". A ideia é simples — mas ela aparece em dois momentos muito diferentes de um sistema de IA:

🍽️ Analogia rápida: pense num restaurante.
• Top‑K na geração = o chef só pode escolher entre K ingredientes para montar o prato.
• Top‑K no retrieval = o garçom só traz K pratos do menu para você escolher.
Os dois usam a mesma palavra, mas um filtra ingredientes e o outro filtra pratos.

Role a página, mexa nos controles e leia as caixas explicativas. No final tem um exemplo prático juntando os dois conceitos num chatbot real e um glossário com todos os termos que aparecem.

🎲 Top‑K na Geração

Filtra tokens candidatos na hora de escrever
❓ O que é: quando uma IA escreve texto, a cada passo ela calcula uma probabilidade para cada palavra possível do vocabulário (podem ser 50 mil!). O top‑K corta essa lista e deixa só as K palavras mais prováveis.
🎯 Pra que serve: evita que o modelo escolha palavras absurdas de baixa probabilidade, mas ainda dá variedade à escrita.
⚙️ Como se controla: um único número, o K. K=1 vira "sempre a mais provável" (repetitivo). K grande = mais criativo, mas pode virar bagunça.
Tokens que o modelo PODE escolher Cortados (probabilidade baixa)
📍 Onde isso aparece na prática:
  • ChatGPT, Claude, Gemini — todos usam top‑k (ou top‑p) para gerar texto.
  • Autocompletar de celular e tradutores automáticos.
  • Geração de código, legendas e resumos.

📚 Top‑K no Retrieval

Filtra itens recuperados de uma base de dados
❓ O que é: quando um sistema busca informação (documentos, produtos, vídeos), ele calcula a relevância de cada item para a sua pergunta. O top‑K pega apenas os K itens mais relevantes e ignora o resto.
🎯 Pra que serve: não adianta mandar 10.000 resultados para o usuário (ou para a IA). Só os K melhores importam.
⚙️ Como se controla: o K aqui é o número de resultados devolvidos. K=3 → "me dá os 3 melhores". K=100 → "me dá os 100 melhores".
Itens que SERÃO entregues Ignorados (baixa relevância)
📍 Onde isso aparece na prática:
  • Buscadores (Google, Bing) — quando você vê "10 resultados".
  • RAG: a IA busca K documentos antes de responder.
  • E‑commerce ("os 5 produtos mais relevantes"), streaming, notícias.

🤖 Juntando os dois: como funciona num chatbot com RAG

RAG (Retrieval‑Augmented Generation) é uma técnica em que a IA primeiro busca informação e depois escreve a resposta. Os dois tipos de top‑K aparecem em sequência:

1️⃣ Você pergunta: "Qual a melhor ração para gatos idosos?"
sua pergunta vira um vetor → compara com a base
2️⃣ Top‑K no RETRIEVAL (K = 3): o sistema busca em milhares de documentos e devolve só os 3 mais relevantes:
📄 Artigo "Nutrição felina sênior" 📄 Guia "Ração para idosos" 📄 Review "Melhores marcas 2024"
Os outros 9.997 documentos foram ignorados.
3️⃣ Top‑K na GERAÇÃO (K = 40): agora o modelo escreve a resposta. A cada palavra, ele considera apenas as 40 mais prováveis do vocabulário:
"Para" "gatos" "idosos" "recomenda‑se" "uma" "ração" …
Palavras como "guarda‑chuva" foram cortadas.
💡 A grande sacada: no passo 2 o top‑K filtra documentos. No passo 3 filtra palavras. É o mesmo nome, mas atuando em camadas totalmente diferentes do sistema.

📖 Glossário rápido

Token
Pedaço de texto (uma palavra, parte de palavra ou símbolo). É a unidade com que modelos de linguagem trabalham.
Vocabulário (vocab)
Conjunto de todos os tokens que um modelo conhece. Pode ter de 30 mil a 200 mil tokens.
Probabilidade / score
Número que indica quão provável (na geração) ou quão relevante (no retrieval) um item é. É por ele que se ordena a lista antes de aplicar o top‑K.
Top‑K
Ficar com os K melhores de uma lista ordenada. O "melhor" é definido pelo score.
Top‑p (nucleus sampling)
Alternativa ao top‑K na geração: em vez de fixar um número K, pega o menor conjunto de tokens cuja probabilidade acumulada passa de p (ex.: 0.9).
Retrieval
Etapa de buscar informação relevante numa base (documentos, produtos, imagens).
Geração
Etapa em que o modelo escreve texto, um token de cada vez.
RAG (Retrieval‑Augmented Generation)
Arquitetura que combina retrieval + geração. A IA busca documentos (top‑K retrieval) e depois escreve a resposta (top‑K generation).
Embedding / vetor
Representação numérica de texto que permite medir similaridade. Usado para ranquear os itens no retrieval.
🧠 Resumo final: top‑K na geração poda o vocabulário do modelo. Top‑K no retrieval poda a lista de resultados. Mesmo nome, papéis diferentes — e agora você sabe reconhecer qual é qual.
