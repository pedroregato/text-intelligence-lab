# ADR-002 — Course Licensing Strategy

## Status
Proposed

## Context
O TIL combina código executável, notebooks, documentação, conteúdo educacional e possivelmente datasets derivados.

Uma única licença pode não representar adequadamente todos esses tipos de artefato.

## Decision
Antes da publicação ampla, o projeto deverá adotar uma política explícita de licenciamento.

Estratégia preferida para avaliação final:

- código: licença permissiva, como MIT ou Apache-2.0;
- conteúdo educacional: CC BY 4.0;
- datasets: licença compatível com a origem e com os direitos de redistribuição.

## Rationale
Separar código e conteúdo evita ambiguidade e facilita reutilização educacional.

## Consequences
Até a decisão final, o README deve declarar que o licenciamento está em formalização.

Nenhum dataset externo deve ser redistribuído sem validação de licença.
